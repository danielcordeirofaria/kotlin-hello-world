# Overview

This is a simple Kotlin console program that prints "Hello, World!" to the screen. I built it to practice a complete development workflow from start to finish: writing and running code in an IDE, using Git for version control, and publishing a project to GitHub. These are the fundamentals I will keep relying on as I take on larger Kotlin projects.

My purpose in creating this program was to get comfortable with my development environment and tools before moving on to more complex work, so that setup and tooling questions do not slow me down later.

[Software Demo Video](https://www.youtube.com/watch?v=IyNT5zFq8cI)

# Development Environment

* IntelliJ IDEA Community Edition
* Git and GitHub

I used Kotlin (JDK 24) as the programming language.
